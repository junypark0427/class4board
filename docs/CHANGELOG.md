# 익명 게시판 → 비공개 건의함 변경

## 유지한 것

Next.js App Router, `app/write` 글쓰기 폼, `/api/posts` 제출 API, Supabase 서버/브라우저 클라이언트, 입력 길이 검증과 서명된 도배 방지 쿠키를 재사용했습니다.

## 바꾼 것

- 첫 화면을 학생 의견 제출 화면으로 바꿨습니다.
- 자유게시글 → 기타. 공개 범위 선택 → 선생님 전달 희망/처리 결과 확인 희망.
- 모든 글을 비공개로 접수합니다. 결과를 원하면 무작위 비밀 확인번호를 발급합니다.
- 상태: 미확인 → 확인 완료 → 선생님께 전달 → 처리 완료. 불필요한 단계는 생략 가능합니다.
- 별도 계정 두 명의 동등 관리자 권한, 상태/분류/숨김 필터, 메모, 작성자 답변, 숨김 복구를 구현했습니다.
- 작업 기록에 담당자와 시간을 남기고, 동시 수정 시 덮어쓰기를 막습니다.
- 초록색·따뜻한 바탕색과 한글 중심의 모바일 폼으로 구성했습니다.

## 비활성화한 것

공개 목록은 더 이상 조회하지 않고 `/posts/[id]`는 데이터 조회 없이 열람 불가 안내로 처리합니다. 이전 공개 화면은 `docs/legacy`에 보관했습니다. 댓글·좋아요·학생 간 상호작용은 만들지 않았습니다.

변경 당시 관리자 화면과 DB 스키마는 미구현 상태여서 이번 비공개 건의함 요구사항을 기준으로 완성했습니다. 기존 운영 DB나 실제 학생 데이터는 없었으며 새 프로젝트를 따로 생성해 교체하지 않았습니다.

## 프로젝트 위치

사용자 요청에 따라 프로젝트 전체를 `~/Documents/Projects/class4board`로 이동했습니다. 소스, 설치 패키지, 빌드 결과, SQL, 검사 코드, 문서와 공개 화면 보관본이 모두 이 폴더 안에 있습니다.
